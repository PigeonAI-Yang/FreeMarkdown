## 面板形态（按反馈调整）

- 面板内**没有工具条**：源码 / 分栏 / 预览的切换、保存状态（未保存 / 保存中 / 已保存 HH:MM）、
  换行（LF/CRLF）与 BOM 徽标全部在顶部工具条上；切换形态时若当前文档还没有编辑面板，会顺手开一个。
- 面板内只保留**必须立刻处理**的现场提示：冲突横幅（覆盖 / 重新载入 / 另存为三个按钮）与保存失败提示。
- 形态存进会话（`editMode`），下次启动沿用。

## 实现要点（对应方案第 4 节）

- **数据流**：按键 → CM6 事务（本地，无 IPC）→ 90ms 防抖 → 只把受影响的顶层块切片发给 Rust →
  comrak 只解析该切片 → 返回块 HTML → 按块局部替换 DOM。前端持文本缓冲，键盘路径不回传全文。
- **切片范围**：文本差异（前缀/后缀比对）→ 行号 → 覆盖该行的块范围向两侧各扩一块（换正确性），
  跨度过大（>4000 行或 >512KB）直接整篇重渲染兜底。
- **链接引用定义**：文档含 `[id]: url` 时把定义作为前缀一起发给 Rust（只参与解析、不产出块），
  避免切片渲染时引用解析失败；含脚注定义 `[^id]:` 的文档退化为整篇重渲染（脚注编号依赖全文顺序）。
- **预览 DOM**：只挂载可视区附近的块（前后各 2 块 + 400px 预挂载），未挂载区域用估算高度占位；
  块按 `data-block` / `data-rev` 版本比对注入，未受影响的块元素身份不变（阶段 2 的"局部替换"验收基础）。
- **保存链路**：临时文件 + rename 原子写；写前比对 mtime，不一致返回 `conflict:<当前 mtime>` 且不落盘；
  换行先归一化再按原风格还原、BOM 原样保留；强杀留下的临时文件会在下次保存时清理。
- **自动保存**：空闲 1s 防抖 + `Ctrl+S` 立即保存 + 编辑器失焦保存 + 冻结/关闭前落盘；冲突未解时不自动覆盖。
- **冻结**：面板不可见即卸载 EditView（CM6 实例与 DOM 全部销毁），`EditorState.toJSON()` 与滚动位置留在
  面板级缓存（最多 4 份，LRU），重新可见时无等待恢复（光标、选区、撤销历史、视口一并回来）。
  恢复时会校验快照：只有"有未保存改动"或"快照内容与磁盘一致"才恢复，避免过期文本被当成已同步。
- **多面板一致**：保存成功后广播 `emitDocSaved(path, mtime)`，同路径阅读面板按新 mtime 重读
  （LRU 以 (路径, mtime) 为键，天然失效）。

## 已知限制与后续（阶段 2 起）

1. **源码 ↔ 预览双向联动**（滚动同步、点击跳转）尚未做，`data-sourcepos` 与前端解析器已就位，属阶段 2。
2. **外部改动监听**：目前只在保存时按 mtime 检测冲突，尚未用 `notify` 常驻监听；阅读面板不会自动热刷新（编辑保存会）。
3. **脚注文档**退化为整篇重渲染（2MB 级会有明显延迟），链接引用定义已按前缀方案处理。
4. **另存为**用系统原生对话框（Tauri dialog），自动化只能覆盖到其落盘路径，按钮行为由人验证。
5. **dev 构建配置**：`src-tauri/Cargo.toml` 增加 `[profile.dev.package."*"] opt-level = 2`。
   默认 opt-level=0 时 comrak 解析 2MB 要 ~1.5s（打开直接超预算），依赖优化后 dev 与 release 同量级。
6. **预览的 mermaid**：打字期间不渲染（降级），停手 320ms 后补跑，保证键入延迟与主线程空闲。
7. **HMR 注意**（开发期经验）：非组件模块（store/ipc 等）被热更新时页面会整页 reload，
   可能短暂出现空布局；`scripts/cdp.mjs reload` 或手动刷新即可恢复，不是运行时缺陷。
